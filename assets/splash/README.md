# Splash Screen Assets

Coloca aquí el archivo de imagen para la pantalla de splash:

## Requerido:
- `splash.png` - Imagen para la pantalla de splash (1152x1152px recomendado)

## Cómo crear la imagen de splash:

### Especificaciones:
- Tamaño recomendado: 1152x1152px
- El logo/imagen debería estar centrado
- Mantén el contenido importante dentro de un área de 768x768px (centro)

### Diseño sugerido:
- Fondo transparente o del color principal (#1E88E5)
- Logo/ícono de la app en el centro
- Puede incluir el nombre "Javerage Todos" debajo del logo

### Herramientas:
- Figma, Adobe Illustrator, o cualquier editor de imágenes
- [Canva](https://www.canva.com/) - Para diseños rápidos

## Color de fondo configurado:
- #1E88E5 (azul material)

## Después de agregar la imagen, ejecuta:
```bash
dart run flutter_native_splash:create
```
